3 · CHAIN READER

Canonical Tobyworld Lore Land Deeds contract. The reader still verifies Base chain ID and that contract bytecode exists before scanning.
How the scan works
The reader pins one Base block, reads balanceOf() for every wallet, then uses ERC-721 enumeration if the collection exposes it. Otherwise it keeps a local contract-wide ownership index built from canonical Transfer events. Later refreshes scan only blocks after the saved cache point. Every token mapped to your wallets is then re-checked with ownerOf() at the pinned block. The cache accelerates discovery; it never replaces live ownership verification.
